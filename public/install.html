Scan to get CFA Spark

Use an iPad or phone camera to open the installation instructions.

cfa-spark.onrender.com/install.html
1

iPad and iPhone · Safari

  1. Scan the QR code or open this page in Safari.
  2. Tap Open CFA Spark to install above.
  3. In Safari, tap Share (square with the upward arrow).
  4. Tap Add to Home Screen. Enable Open as Web App if offered, then tap Add.
2

Android · Chrome

  1. Open this page in Chrome.
  2. Tap Open CFA Spark to install.
  3. Open Chrome's menu (⋮), then select Install app or Add to Home screen.
  4. Confirm the installation to add CFA Spark to the device.
Private restaurant workspace: The Home Screen installation is free, but using CFA Spark requires an approved team account. An internet connection is needed to save checklists and temperature readings.
